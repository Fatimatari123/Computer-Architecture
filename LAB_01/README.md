# Apply modern simulation tools ModelSim and
# Logisim to implement basic processor components

In this module, basic gates were implemented in ModelSim using Verilog HDL at both the gate level and the dataflow level, and then the gates on Logisim. An XOR gate was also implemented on Logisim and Modelsim using Gate level and Dataflow level Verilog HDL.

Then, a Verilog code was written to find the 1’s complement of four bits using gate level and
data flow
modeling and verifying results using a testbench.
